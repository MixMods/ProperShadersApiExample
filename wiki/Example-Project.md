# Example Project

A complete, buildable Plugin-SDK mod ships alongside this documentation:
**`ProperShadersApiExample`**. Press **F7** in game and it toggles a spot light in the
middle of Grove Street, pointing straight down and glowing in the volumetric fog.

It is written to be read rather than just run — `Main.cpp` walks through loading the
API, creating a light, keeping its handle, and removing it again, including the path
where Proper Shaders is not installed at all. If you are starting an integration, copy
that file and delete what you do not need.
